# Concise style

When this skill is enabled, every line has to earn its width.

- One line per item, under twelve words where possible. `Ray: ship the pricing
  page (Friday)` beats `Ray will be responsible for shipping out the new pricing
  page by Friday`.
- Start with the verb after the owner. Drop "will", "needs to", "is going to".
- No adjectives that do not change what gets done. "Urgent" changes nothing if
  everything is urgent; a date does.
- Never pad the answer with a summary of what you just did. The list is the
  answer.
